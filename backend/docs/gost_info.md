# Требования к структуре учебно-методических материалов (УММ) в РФ

Сводка подготовлена на основе действующих ГОСТов и методических рекомендаций для высших учебных заведений Российской Федерации.

---

## 1. Нормативная база

| Документ | Содержание |
|---|---|
| **ГОСТ 7.60-2003** | «Издания. Основные виды. Термины и определения» – определяет виды учебных изданий и их назначение |
| **ГОСТ 7.32-2017** | «Отчёт о НИР. Структура и правила оформления» – применяется для методических указаний и учебных пособий |
| **ГОСТ 7.1-2003** | «Библиографическая запись. Библиографическое описание» – общие требования к списку литературы |
| **ГОСТ Р 7.0.100-2018** | «Библиографическая запись. Библиографическое описание» – актуальный стандарт библиографии |
| **ГОСТ Р 55751-2013** | «Электронные учебно-методические комплексы. Требования и характеристики» – для ЭУМК |
| **ГОСТ Р 7.0.110-2025** | «Оформление научных и учебных текстов» – шрифты, заголовки, таблицы, иллюстрации (введён с 2025 г.) |

---

## 2. Обязательные разделы по видам УММ

### 2.1 Учебное пособие (включая учебно-методическое)

- **Оглавление (содержание)** – в начале издания
- **Введение** – цель, читательский адрес, актуальность, методические рекомендации
- **Основная часть** – тематические разделы с выводами и дидактическим аппаратом
- **Заключение** – основные итоги, выводы, нерешённые проблемы
- **Справочно-библиографический аппарат** – список литературы, приложения (при наличии)

**Дополнительные требования:**

- Тематические разделы должны содержать выводы и дидактический аппарат (контрольные вопросы, примеры, упражнения, задачи, тесты) для самоконтроля студентов
- Содержание должно соответствовать ГОС ВО и утверждённой учебной программе дисциплины

### 2.2 Методические указания / Методические рекомендации

- Содержание
- Введение
- Основная часть
- Заключение
- Список использованных источников
- Приложения

> **Примечание:** Структурные элементы «Содержание», «Введение», «Основная часть», «Заключение», «Список использованных источников» и «Приложения» **не нумеруются**.

### 2.3 Электронный учебно-методический комплекс (ЭУМК)

По ГОСТ Р 55751-2013 в состав ЭУМК входят:

- Рабочая программа дисциплины
- Электронное учебное пособие
- Методические указания по изучению дисциплины
- Контрольно-измерительные материалы (тесты, задания)
- Список литературы и информационных источников
- Наглядные материалы (при необходимости)

### 2.4 Учебно-методический комплекс дисциплины (УМКД)

Типовой состав:

- Введение (при необходимости)
- Область применения
- Нормативные ссылки
- Рабочая программа дисциплины
- Паспорт дисциплины
- Виды и содержание занятий
- Формы и содержание текущей аттестации и итоговой оценки

## 4. Примечания по оформлению

- **Структурные элементы** «Содержание», «Введение», «Основная часть», «Заключение», «Список использованных источников» и «Приложения» начинаются с новой страницы и **не нумеруются**.
- **Библиографическое описание** выполняется по ГОСТ Р 7.0.100-2018.
- При оформлении текста рекомендуется учитывать **ГОСТ Р 7.0.110-2025** (шрифты, абзацы, таблицы, формулы).
