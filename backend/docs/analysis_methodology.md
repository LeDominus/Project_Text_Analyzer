# Методика анализа текстовых файлов и формирования рекомендаций

## Общая методология анализа

Проект реализует комплексную методику анализа текстовых документов в официально-научном стиле, основанную на многомерной оценке ключевых параметров текста. Методика включает последовательное применение специализированных аналитических модулей, каждый из которых оценивает определенный аспект качества текста.

## Этапы анализа и соответствующие методы

### Этап 1: Предварительная обработка текста
**Метод**: `TextPreprocessor`
- Извлечение текста из PDF-документов
- Нормализация и очистка текста
- Разделение текста на логические секции для последующего анализа

### Этап 2: Анализ когерентности
**Метод**: `CoherenceAnalyzer` с использованием SentenceTransformer
- Разделение текста на секции по 30 предложений
- Генерация эмбеддингов для каждой секции с помощью BERT-модели
- Расчет косинусного сходства между последовательными секциями
- Вычисление среднего показателя когерентности

**Интерпретация результатов**:
- ≥ 0.75: Текст имеет связную структуру
- 0.5–0.75: Текст имеет проблемы с логикой
- < 0.5: Текст логически не связан

### Этап 3: Анализ структуры
**Метод**: `StructureAnalyzer` с регулярными выражениями
- Идентификация структурных элементов по шаблонам:
  - Введение, заключение, главы, приложения
  - Список литературы, содержание, аннотация
- Сравнение структуры анализируемого текста с эталонным документом
- Взвешенная оценка соответствия структурных элементов

**Интерпретация результатов**:
- ≥ 0.75: Структура текста соответствует стандартам
- 0.5–0.75: Структура текста требует доработки
- < 0.5: Структура текста не соответствует стандартам

### Этап 4: Анализ читаемости
**Метод**: `ReadabilityAnalyzer` на основе индекса Флеша для русского языка
- Расчет лингвистических параметров:
  - Количество предложений, слов, слогов
  - Средняя длина предложения и слова
- Вычисление индекса Флеша по адаптированной формуле

**Интерпретация результатов**:
- > 90: Для младших классов
- > 60: Для средней школы
- > 30: Для студентов ВУЗов
- ≤ 30: Для специалистов

### Этап 5: Извлечение ключевых слов
**Метод**: `KeywordExtractor` на основе TF-IDF
- Применение векторизатора с n-граммами (1-2)
- Использование стоп-слов для русского языка
- Фильтрация числовых значений и коротких слов
- Ранжирование фраз по значимости

### Этап 6: Формирование рекомендаций
**Метод**: `LLMApi` с YandexGPT
- Интеграция всех результатов анализа
- Генерация единой комплексной рекомендации
- Фокус на 2-3 ключевых направлениях улучшения
- Предложение практических шагов по внедрению

## Результаты на каждом этапе

Каждый этап анализа формирует количественные и качественные показатели, которые интегрируются в единую модель оценки качества текста. Окончательный результат представлен в виде `AnalysisResult`, содержащего все метрики и рекомендации в структурированном формате, пригодном для дальнейшего использования в пользовательском интерфейсе.
